# RF Front-End Simulation

Simulation and performance analysis of an RF front-end for a conversion receiver using Cadence AWR Microwave Office (MWO).

## Overview

This project focuses on the simulation and evaluation of an RF front-end operating at **4.25 GHz**. The receiver consists of a **Low Noise Amplifier (LNA)**, **RF Filter**, **Balanced Mixer**, **Local Oscillator (LO)**, and **IF Filter**.

The main objective is to evaluate the performance of each block by analyzing key RF metrics such as gain, noise figure, linearity, and modulation quality.

## System Specifications

| Parameter | Value |
|-----------|------:|
| RF Frequency | 4.25 GHz |
| LO Frequency | 3.75 GHz |
| IF Frequency | 500 MHz |
| Modulation | 16-QAM |
| Bandwidth | 32 MHz |

## Simulations

The following analyses were performed:

- LNA Performance Evaluation
- Mixer Performance Evaluation
- Noise Figure (NF)
- Gain and Conversion Gain
- P1dB and IP3
- Error Vector Magnitude (EVM)
- Phase Noise Analysis
- Image Interference Analysis

## Software

- Cadence AWR Microwave Office (MWO)
